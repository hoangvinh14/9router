## Code execution: missing monetary quantity and tenant resource ownership

Code docs distinguish two regimes:

1. Web search/fetch20260209+ included: code execution has no additional operation charge. This applies to direct code and dynamic filtering. Any nonbillable claim must be selected by validated original tool version set, not caller count or global default.
2. Standalone code: billed by execution time per container, minimum5minutes, shared organization free allocation1550hours/month, additional per-hour price; files may incur execution time even if tool not called. Public example reports only `code_execution_requests:1`, not elapsed billable duration. **Request count is not time.** No exact per-attempt elapsed charge quantity is established by this page or historical stable SDK. Do not translate request count into5minutes/hours, allocate organization free credit per gateway key, or copy public rates into production.

Standalone code is therefore an evidenced monetary observability blocker until exact upstream duration/billable attribution or an explicit operator-approved reference-cost contract exists. Existing embedded-fee decision does not authorize inventing a duration. This blocker is not completion-by-refusal; accepted obligation stays open.

Containers and files are workspace-scoped upstream. Original arbitrary container ID/file_id under a shared provider connection is not gateway-key ownership. Reuse/expiry/deletion/import/restore and credential/workspace binding must be durable before cross-request resource references can be admitted. Generated file output belongs to the issuing gateway key/attempt; IDs must not grant other keys shared-workspace access. Existing file security blocker carries forward to containers, not resolved by ID regex or dummy result fixture.

Dynamic filtering may generate code calls without explicit code tool declaration, response_inclusion can remove complete nested pairs, caller IDs bind search/fetch to code parent, and deferred/pause relationships span generations. Need a bounded multi-tool graph owner with raw usage authority, no count-from-block estimate. Static direct-search owner cannot be relaxed into that implementation by accepting arbitrary caller fields.

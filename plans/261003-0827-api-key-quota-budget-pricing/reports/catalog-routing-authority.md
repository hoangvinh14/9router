## Implementation and security notes

`capabilityRoutingAuthority.js` checks the global slot descriptor without invoking accessors. Only a source registered by the standard installer's private WeakSet, with exact plain callback descriptors, is accepted. Arbitrary/proxy/accessor sources are refused without callback execution. Source object identity and full lexical file text become internal equality material, never logs/ledger/export.

Installed-source file reads use the fixed server path, `O_NOFOLLOW | O_NONBLOCK`, regular-file checks, existing262144-byte ceiling plus one bounded detection byte, fatal UTF-8 and bounded plain JSON validation. Only ENOENT at open is absence; malformed/oversized/symlink/FIFO/read failures refuse. Standard cache is invalidated so same-mtime edits cannot leave retained cache permission. Existing aggregate material/queue bounds still apply; no pruning for large catalogs.

Self-review added O_NONBLOCK because FIFO could otherwise block before fstat. This is a local Linux-tested guard, **not independent security review**, universal platform parity, process sandboxing, HMR compatibility or physical power-loss evidence. Module-copy/HMR provenance may fail closed and remains a compatibility obligation. No secrets/catalog body are emitted.
